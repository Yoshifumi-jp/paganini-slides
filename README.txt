悪魔と呼ばれたヴァイオリニスト ― パガニーニ
（中学生向け音楽教材・デモ）

■ 見方
1. このフォルダの「index.html」をダブルクリックします（Microsoft Edge 推奨）
2. 「▶ はじめる」を押すと、音楽とナレーションが始まります
3. → キー（またはクリック）で次へ進みます。A キーで最後まで自動再生します
   ※ インターネット接続は不要です。フォルダの中身（css・js・vendor・assets）は移動・削除しないでください

■ 操作キー
→ / Space / クリック ：次へ（演出の途中なら演出を最後まで表示）
← ：前へ　　Home / End ：最初 / 最後
A ：自動再生 ON/OFF　　N ：ナレーション ON/OFF　　M ：音を消す
F ：全画面　　? ：操作ヘルプ
1〜4 ：6ページ「超絶技巧 体験ラボ」の音、14ページのクイズの回答

■ 内容（全14ページ・約10分）
パガニーニの生涯（1〜8ページ）と、その後の音楽への影響（9〜13ページ）、まとめクイズ（14ページ）

■ ナレーションの声
パソコンに入っている日本語の読み上げ音声を使います（Windows の「Haruka」を優先）。
音声がない環境では字幕だけで進みます。

■ 録音と出典
・ルッジェーロ・リッチ（1947年）、パデレフスキ（1927年）、ラフマニノフ本人（1934年）の録音を使用しています。
  日本の著作権法では、1967年以前に発行された録音の著作隣接権は保護期間が満了しています。
  海外で公開する場合は、その国の保護期間を確認してください。
・出典の一覧は最後のエンドロール、および assets/CREDITS.md にあります。
